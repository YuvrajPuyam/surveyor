# Hackathon context — Worlds in Action Hack [02-LA]: SIGGRAPH EDITION

Source: https://luma.com/u7pmhw92 (fetched 2026-07-05). Re-fetch occasionally; the
event page may gain judging details closer to the date.

- **Event:** Worlds in Action Hack [02-LA], SIGGRAPH Edition. Los Angeles,
  weekend right before SIGGRAPH 2026 (~Jul 18): Friday warm-up, main hack
  Saturday–Sunday.
- **Hosts:** SensAI Hackademy, Poeia XR, Machine Cinema, FBRC.AI, AI LA.
- **Theme:** "Two days to build the future of interactive AI worlds" — world
  models, generative AI, spatial computing.
- **Six tracks:** film/entertainment experiences, games, interactive ads,
  agentic systems, world models with 3D GenAI, 3D reconstruction.
- **Sponsor tech emphasized:** World Model APIs (World Labs), open-source world
  model kits (Unity/Unreal/WebXR), WebSpatial deployment, MCP connectors,
  Gaussian splat systems, VFX/3D GenAI pipelines.
- **Prizes:** $10,000 pool, $2,000 World Labs API credits, XGRIDS PortalCam
  (~$5,000), SIGGRAPH 2026 tickets, showcase at SIGGRAPH '26.

**Where SURVEYOR sits:** strongest fit is the *agentic systems* and *3D
reconstruction / world models with 3D GenAI* tracks — we consume World Labs
(Marble) worlds, certify their physics with a measurement instrument, and repair
them with a Claude agent loop over MCP. Judges at this event care about world
models, splats, and agents — all three are load-bearing in our demo.
