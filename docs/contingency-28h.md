# Contingency scope — 28 build hours only (pre-committed Jul 4)

Fires if Gate B fails (no written organizer permission for the pre-event
library by **Jul 8 EOD**). In that case NOTHING built pre-event ships in the
submission; pre-event time converts to **science, content, and rehearsal** —
all rules-safe — and the app is written entirely on-site.

## What pre-event time becomes (all non-code or non-shipping)

- **Science:** verify collider/splat coordinate frames; measure vendor scale
  metadata accuracy vs hand-measured door heights; panorama conversion recipe
  iterations; physics formulas for the gravity suite (all documented in
  notebooks/slides, reproducible on-site).
- **Content:** hero world curation (worlds are assets, not code), Mastcam-Z
  panorama conversions, pre-generated Mars world, Isaac receipt clip
  (evidence video, not app code), robot spec cards, certificate visual design
  mockups.
- **Rehearsal ops:** demo script, timing, hostile-judge Q&A drills, Devpost
  draft, cut ladder.
- **Skills, not artifacts:** dry-run building the probe engine once as a
  throwaway exercise (delete after), so the on-site rebuild is fast and
  familiar. Knowledge is not a rules violation; shipped code is.

## What gets cut relative to the full plan

- Agent-directed probing → scripted sweep only, narrated ("agent layer" line
  goes to roadmap; do NOT fake it — agent-washing loses the primary track)
- MCP front door → roadmap slide
- Fail-and-adapt repair beat → single clean repair
- Self-validation suite → one planted-defect world, one sentence
- Mars flourish stays ONLY if the pre-generated world exists (content, not code)
- Replay cassette → simple screen-recording backup video

## Non-negotiables that survive any cut

1. Raycast cross-check (tunneling never reads as a hole)
2. Uncertainty + methods line on every number
3. Two-robot relative verdicts (the sill moment)
4. "Unchanged under Mars gravity" honesty beat
5. Rehearsal hours (features get cut, rehearsal time never does)
