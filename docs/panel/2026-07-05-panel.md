The repo already demonstrates the hard part: a machine-readable certificate that changes downstream robot behavior, byte-reproducibly.
- **The defect-outcome ledger becomes the world-model feedback loop**: Today: every defect ends in exactly one audited outcome (fixed/quarantined/escalated/accepted — 75/75 recorded on the habitat), and escalation already means 'regenerate with an adjusted prompt' (PLAN §15 scope fence). The certifier stops being downstream QA and becomes the objective function world models optimize against. _Why it wins:_ Deterministic, cheap ($0.12/draft world), fully automated grading is exactly what an RLHF-style loop over world generation needs, and the repo already has every component: generate CLI (scripts/marble.ts), headless certify, byte-identical outputs.
